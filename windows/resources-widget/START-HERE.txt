СИСТЕМНЫЕ РЕСУРСЫ 1.1.1 / RESOURCES WIDGET 1.1.1

РУССКИЙ

Готовая программа для Windows 10 (1903+) / Windows 11, x64, .NET Framework 4.8. Собирать исходники не нужно. Распакуйте всю папку resources-widget в обычную папку с правом записи и запустите ResourcesWidget.exe. Не запускайте программу прямо внутри ZIP и не переносите один EXE без config.json.

Значок появляется в области уведомлений Windows. Карточка открывается щелчком по значку или Ctrl+Alt+R. Через меню значка можно включить автозапуск; по умолчанию он выключен. Выход — через меню значка. Закрепление поверх окон, разделы, тема, масштаб и компактный режим настраиваются там же.

Сеть работает сразу: скорости, пиковые значения, трафик, ICMP-пинг до основного шлюза (роутера) и 1.1.1.1 каждые 2 секунды. Щелчок по пикам открывает журнал: дни, минутные графики, потери, обрывы, высокий пинг и смена скорости соединения. Локальные файлы network-log сохраняются на 400 дней. Учитывается только этот компьютер и только время работы виджета. Поле internetMbps в config.json задаёт скорость вашего тарифа; 0 использует скорость адаптера. Пустой pingHost отключает оба пинга. После правки config.json используйте перезапуск из меню.

Температура процессора: при установке можно выбрать «Локальный датчик температуры процессора (с драйвером PawnIO)». Windows запросит обычное подтверждение администратора. Установщик размещает собственный помощник в защищённой папке %ProgramFiles%\ResourcesWidgetSensor\<SID>, создаёт отдельную задачу SYSTEM при входе вашего пользователя и ставит подписанный PawnIO только если совместимый драйвер недоступен. Помощник напрямую читает библиотеку датчиков без HTTP/сетевого сервера и без запуска LibreHardwareMonitor. Виджет читает только локальный защищённый temperature.json; снимок старше 5 секунд, повреждённые данные и ошибки не показываются как свежая температура. Настроенные внешние HWiNFO/AIDA64/Core Temp/LibreHardwareMonitor продолжают работать как запасные источники. Параметр lhmUrl относится только к отдельному внешнему LibreHardwareMonitor; пустая строка отключает этот опрос, собственному помощнику HTTP не нужен.

Установщик ставит сам виджет для текущего пользователя в %LOCALAPPDATA%\Programs\ResourcesWidget, создаёт ярлыки и запись в установленных приложениях. Обновление сохраняет config.json и state.json; перед обновлением сохраните копию всей папки вместе с network-log. Установщик принимает отдельную новую/пустую папку либо подтверждённую установку. Удаление убирает известные файлы приложения; настройки, журналы и посторонние файлы сохраняются в папке. Датчик обновляется и удаляется через меню виджета; если сам виджет уже удалён, используйте отдельную запись «Системные ресурсы — локальный датчик температуры» в установленных приложениях Windows. Удаление виджета отдельно предлагает удалить его помощник; общий драйвер PawnIO, сторонние программы и их настройки сохраняются. При самостоятельном удалении management-файла его уникальная копия может остаться до перезагрузки; повторная установка до перезагрузки безопасна. Сам виджет и установщик не имеют цифровой подписи; Windows может показать предупреждение о неизвестном издателе. Подробности сторонних компонентов — THIRD-PARTY.txt.

ENGLISH

Ready-to-run Windows 10 (1903+) / Windows 11 x64 application; .NET Framework 4.8 is required. Extract the entire resources-widget folder to a writable location and run ResourcesWidget.exe. No source build is required. Keep config.json beside the EXE. Do not run inside the ZIP.

Open the tray card by clicking its icon or pressing Ctrl+Alt+R. Use the tray menu to quit or opt into Windows startup; startup is disabled by default. The menu also controls theme, size, compact view, visible sections and always-on-top.

Network monitoring is enabled: traffic, peaks, ICMP probes to your default gateway and 1.1.1.1 every two seconds. Click the network peaks to open daily history, minute graphs and connection events. Local network-log files are retained for 400 days and cover only this computer while the widget is running. Set internetMbps to your plan speed; 0 uses adapter link speed. Set pingHost to an empty string to disable both probes. Restart from the tray menu after editing config.json.

CPU temperature can be installed by selecting the optional Local CPU temperature sensor (PawnIO driver) checkbox. Windows requests normal administrator consent. The installer places an independent read-only helper under protected %ProgramFiles%\ResourcesWidgetSensor\<SID>, with its own SYSTEM task triggered at your user logon. A signed PawnIO driver is installed only if a compatible service/device is unavailable. The helper directly reads LibreHardwareMonitorLib.dll and publishes a protected local temperature.json; it opens no HTTP/pipe/network server, launches no LHM GUI and changes no external monitor settings. Snapshots older than five seconds, malformed values, errors and future timestamps are rejected. Existing HWiNFO/AIDA64/Core Temp/LHM readers remain available as fallback sources. The lhmUrl setting is only the independent external LHM client; the bundled helper does not use HTTP. Install/update/remove the helper from the widget menu or its separate Windows Installed Apps entry. Widget uninstall offers helper removal separately. Shared PawnIO and unrelated LHM software remain untouched. A management executable removed from itself may leave a uniquely named tombstone until reboot; a new installation is never scheduled for deletion. Setup accepts a dedicated new/empty folder or a verified previous installation, preserves config/state during upgrades, and preserves settings/logs/unrelated files during widget uninstall. Startup remains opt-in. The custom executables are unsigned; Windows may display an unknown-publisher warning. Bundled dependencies and licenses are documented in THIRD-PARTY.txt.
