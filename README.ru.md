# Виджеты рабочего стола

[English](README.md) · [Страница проекта](https://nikolaykazakovvs-ux.github.io/desktop-widgets/)

Два компактных виджета для Windows: **«Лимиты нейросетей»** показывает расход подписок, **«Системные ресурсы»** — нагрузку компьютера и сеть. C# и Windows Presentation Foundation (WPF), значок в трее, горячие клавиши, светлая и тёмная темы, перемещаемые карточки. Интерфейс приложений сейчас на русском.

## Платформы

Desktop Widgets — общий проект. **Текущий пакет — раздел Windows**, исходники находятся в `windows/`.

| Платформа | Доступность |
| --- | --- |
| Windows | Альфа, исходники в этом репозитории |
| macOS | Планируется отдельная реализация; исходников и загрузки пока нет |
| Linux | Планируется отдельная реализация; исходников и загрузки пока нет |

**Альфа, распространение в исходниках.** Подписанного установщика и готового релиза в этом репозитории нет. Интеграции зависят от приложений провайдеров. Локальная сборка не доказывает совместимость со всеми версиями Windows и оборудованием.

## Лимиты нейросетей

Карточки Claude Code, Kimi Code, Antigravity и GPT / Codex: доступные окна лимитов, время сброса, кредиты и дополнительный расход, когда источник их возвращает. После ошибки предыдущий успешный снимок может показываться как устаревший. Отсутствующие данные не превращаются в нулевой расход. Есть порядок карточек, масштаб, прозрачность, закрепление и компактный режим.

**Все провайдеры выключены по умолчанию**, в том числе при отсутствии конфига. После включения выбранные провайдеры опрашиваются автоматически: по умолчанию раз в 300 секунд, минимум — 60 секунд. Это независимый локальный проект.

| Провайдер | Реализованный источник и доступ |
| --- | --- |
| Claude Code | Установленный `claude`: служебный запрос `get_usage` в потоковом режиме, запасной `/usage`. При отсутствии входа в CLI может читать локальную историю расхода приложения Claude — `plan-usage-history.json`. Действие входа по запросу пользователя запускает авторизацию CLI. |
| GPT / Codex | Запускает `codex app-server`, отправляет `account/rateLimits/read` через стандартные потоки ввода/вывода. Авторизацией управляет сам CLI. |
| Antigravity | Выполняет `agy -p "/usage" --output-format json`, для кредитов — `/credits`. Требуется совместимый CLI с его собственной авторизацией. Работа с любой версией не гарантируется. |
| Kimi Code | Находит работающий локальный сервер приложения, читает `server.token` и использует его для запроса лимитов через loopback. **Этот локальный серверный токен читается и при `allowLocalTokens: false`.** Если включить `allowLocalTokens`, запасной путь читает OAuth access token из файлов авторизации Kimi Code и отправляет его на настроенный endpoint лимитов Kimi. Сам виджет токен не обновляет. |

Параметр `allowLocalTokens` ограничивает только **прямой запасной путь Kimi**, а не любой доступ к авторизации. Перед включением изучите исходники провайдера. Не задавайте недоверенный `baseUrl` для Kimi: прямой запрос отправляет туда bearer token. В примере конфига этот режим выключен.

## Системные ресурсы

Загрузка процессора и отдельных потоков, память, видеокарта, диски, скорость сети и ведущие процессы. Локальный журнал сети хранит трафик, пики и перебои. Для NVIDIA используются данные драйвера, запасной источник — Windows Display Driver Model (WDDM). Температура процессора может поступать из отдельно установленных HWiNFO, AIDA64, Core Temp, LibreHardwareMonitor или OpenHardwareMonitor; показания зависят от оборудования, прав и внешней программы.

Драйверов мониторинга, установщика датчика и сторонних бинарных файлов в пакете нет. Интеграция с установщиком сохранена в коде, но setup здесь не распространяется. Недоступные показания остаются недоступными. В публичных настройках выключены внешний ping и HTTP-источник LibreHardwareMonitor; при необходимости задайте `pingHost` и `lhmUrl`. Локальный сбор показателей и журнал сети работают после запуска приложения.

## Сборка и запуск

Нужны Windows x64, Windows PowerShell и .NET Framework 4.8 с 64-битным компилятором C# и библиотеками WPF. .NET SDK и установка пакетов не требуются. Целевые системы — Windows 10/11 x64; опубликованной матрицы совместимости пока нет.

Вставить в **Windows PowerShell** из корня репозитория; для самостоятельной сборки или агента Codex:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\windows\limits-widget\build.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\windows\resources-widget\build.ps1
```

Сборка создаст локальный `config.json` из `config.example.json`, только если его ещё нет, и положит exe рядом с исходниками. Скрипты не закрывают работающие виджеты. Если выходной exe занят, завершите его вручную перед пересборкой.

Вставить в **Windows PowerShell** из корня репозитория; для пользователя или агента Codex:

```powershell
.\windows\limits-widget\LimitsWidget.exe --show
.\windows\resources-widget\ResourcesWidget.exe --show
```

Войдите в нужные сервисы штатно через их приложения или CLI. В локальном `windows/limits-widget/config.json` поменяйте `services.<провайдер>.enabled` на `true` только для нужных провайдеров. Необязательный `command` позволяет указать локальный путь CLI. Секреты в конфиг не записываются.

Щелчок по трею показывает и скрывает карточку. Горячие клавиши: **Ctrl+Alt+L** и **Ctrl+Alt+R**. В меню — тема, закрепление, масштаб и автозапуск. **Первый запуск публичной копии не включает автозапуск Windows и не меняет видимость значка в области уведомлений.** Автозапуск включается вручную через меню. Выход — там же.

Папка приложения должна разрешать запись: настройки, снимки и журналы сохраняются рядом с exe. Повторный запуск другой копии того же виджета может показать уже работающий экземпляр: используются именованные объекты одного экземпляра в текущей пользовательской сессии.

## Локальные данные

- «Лимиты» сохраняет `state.json` с настройками, снимками лимитов и историей кредитов, а также `widget.log`. Включённые провайдеры запускают соответствующие CLI и запросы Kimi, описанные выше.
- «Ресурсы» сохраняет состояние, диагностический журнал и `network-log/`. Экспорты могут содержать названия процессов, устройств, адаптеров и диагностические пути. Перед отправкой проверяйте и обезличивайте их.
- Реальные снимки, файлы авторизации, журналы, личные конфиги и готовые exe в репозиторий не включены. `.gitignore` исключает их из новых добавлений, но не обезличивает произвольный экспорт.
- Публичная HTML-страница не опрашивает сервисы, не использует аналитику и внешние шрифты. Все цифры в её карточках **демонстрационные**, это не живые аккаунты и не скриншот приложения.

## Структура и проверка

`windows/limits-widget/` и `windows/resources-widget/` содержат исходники, иконки, скрипты сборки и примеры конфигов. `docs/` — готовая статическая страница без сборщика. Её можно открыть как локальный файл или через любой статический HTTP-сервер. Для GitHub Pages используется папка `docs` ветки `main`; относительные ссылки поддерживают `/desktop-widgets/`.

Публичная копия скомпилирована локально установленным компилятором Windows Framework. Проверены JSON конфигов и локальные ссылки. Авторизованные запросы провайдеров, интерактивный запуск приложений, матрица оборудования, установщик, подпись и обновления в рамках этого пакета не проверялись. [Правила участия](CONTRIBUTING.md).
