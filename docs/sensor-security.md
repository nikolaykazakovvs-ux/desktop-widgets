# Локальный датчик температуры процессора

В коллекции v0.1.1 «Системные ресурсы» 1.1.1 возвращают штатную установку температурного датчика через отдельный локальный помощник. Основной виджет работает с обычными правами; доступ к аппаратному датчику выполняет изолированный помощник. Он использует библиотеку LibreHardwareMonitor напрямую, без запуска её графического приложения или HTTP-сервера.

## Установка и использование

В установщике доступна необязательная галочка «Локальный датчик температуры процессора (с драйвером PawnIO)». Изначально она выключена. При выборе Windows запрашивает обычное подтверждение администратора. Добавить помощник позже можно через меню «Установить локальный датчик температуры…».

Для доступа к оборудованию используется PawnIO. Установщик проверяет доступность его устройства и службы; при необходимости применяет закреплённый официальный установщик с проверкой контрольной суммы и цифровой подписи. Уже настроенный внешний LibreHardwareMonitor, его процессы, настройки и автозапуск не изменяются.

Недоступный датчик показан прочерком. Файл с показаниями неправильного формата, из будущего либо старше пяти секунд не используется; другие поддерживаемые источники температуры остаются доступными. Это проверка свежести данных, а не гарантия наличия датчика у любого процессора.

## Локальная граница

| Часть | Контракт |
| --- | --- |
| Сбор | Только аппаратные датчики процессора через закреплённую библиотеку LibreHardwareMonitor; обновление примерно раз в секунду |
| Передача | Атомарно заменяемый temperature.json в защищённом каталоге помощника |
| Содержимое | Только версия формата, идентификатор пользователя, время UTC, температура, обозначение датчика и статус: schema, userSid, utc, temperatureC, sensor, status |
| Размещение | Program Files / ResourcesWidgetSensor / идентификатор пользователя Windows (SID) |
| Запись | Только SYSTEM и администраторы; целевой пользователь может читать |
| Сетевой доступ | NETWORK запрещён в списке доступа к каталогу; помощник не создаёт HTTP-сервер, сетевой listener или канал удалённого управления |
| Запуск | Собственная задача ResourcesWidgetSensor-{SID} от SYSTEM при входе целевого пользователя; фиксированные защищённые исполняемый файл и рабочая папка |
| Основное приложение | Читает локальные показания без повышения прав; пользовательские конфиги не служат исполняемыми командами привилегированной задачи |

Защита каталога ограничивает подмену программы и показаний обычным пользователем. Она не является защитой от локального администратора или SYSTEM. Сетевые проверки самого виджета — отдельная функция журнала и не часть температурного помощника.

## Существующие источники и удаление

HWiNFO, AIDA64, Core Temp и отдельно настроенный LibreHardwareMonitor продолжают поддерживаться. Прежний локальный HTTP-клиент предназначен только для независимо настроенного внешнего LibreHardwareMonitor. Он не нужен собственному помощнику и не означает, что установщик запускает веб-сервер.

При удалении виджета отдельно предлагается удалить его помощник. Удаляются только собственная задача и известные файлы помощника для этого пользователя. Общий драйвер PawnIO сохраняется: он может использоваться другими программами. Чужие установки LibreHardwareMonitor не удаляются.

## Проверка и границы

Этот документ описывает контракт версии, а не свидетельство установки на каждом компьютере. Извлечение установщика, сборка и автоматические тесты не заменяют фактическую установку с повышением прав, проверку ограничений доступа, отсутствие сетевых слушателей, обновление показаний и штатное удаление. Выполненные проверки и оставшиеся ограничения должны указываться в [заметках релиза](https://github.com/nikolaykazakovvs-ux/desktop-widgets/releases/tag/v0.1.1).

Доступность температуры и расход ресурсов зависят от оборудования, драйвера и библиотеки. Установленная библиотека не доказывает поддержку всех процессоров или всей линейки AMD/Intel.
